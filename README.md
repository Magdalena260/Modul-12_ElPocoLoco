# El Pollo Loco

A small jump-and-run browser game built with HTML, CSS and JavaScript.

Help Pepe survive the desert, collect coins and bottles, defeat chickens and fight the endboss!

This project was created as part of the Developer Akademie web development course.

---

## Features

- Jump-and-run gameplay
- Animated character
- Multiple enemy types
- Endboss battle
- Collect coins and bottles
- Throwable bottles
- Sound effects & background music
- Mute button
- Responsive mobile controls
- Rotate-device warning for portrait mode
- Win & Game Over screens
- Restart without page reload

---

## Controls

| Key | Action |
|------|------|
| Left / Right Arrow | Move |
| SPACE | Jump |
| D | Throw bottle |

Mobile touch controls are available on smaller devices.

---

## Mobile Support

The game supports:
- Desktop
- Tablet
- Mobile landscape mode

Portrait mode displays a rotate-device warning.

---

## Technologies

- HTML5
- CSS3

- Canvas API
- Object-Oriented Programming (OOP)

## Project Structure

```text
models/      -> game classes

img/         -> images & sprites
assets/      -> sounds & music

```
